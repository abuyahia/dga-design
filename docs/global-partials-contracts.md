# عقود Global Partials

هذه عقود تركيب للدفعة 3.1؛ التنفيذ في الدفعة الرابعة. تعتمد على Tokens ثم Base ثم Core. لا تعتمد على Template أو Sector Kit ولا تفرض محتوى جهة بعينها.

| الجزء | المدخلات والـslots | المسؤولية والسلوك |
|---|---|---|
| Header | هوية مرتبطة بالرئيسية، اسم الجهة، navigation، utilities، language switch | landmark واحد `header`؛ زر القائمة يعلن expanded وcontrols؛ القائمة المغلقة لا تحتوي عناصر قابلة للتركيز؛ Escape يعيد التركيز للزر |
| Main Navigation | عناصر `{label, href, current, children}` | `nav` باسم فريد؛ روابط حقيقية، `aria-current="page"` للحالي؛ الإفصاح بأزرار مستقلة؛ لا استخدام role=menu لتصفح الموقع |
| Breadcrumb | قائمة أسلاف ثم الصفحة الحالية | `nav` باسم مسار التنقل وقائمة مرتبة؛ الحالية نص أو رابط current=page؛ فواصل زخرفية مخفية عن قارئ الشاشة |
| Footer | هوية، مجموعات روابط معنونة، بيانات اتصال، روابط قانونية، حقوق النشر | `footer` على مستوى الصفحة؛ ترتيب DOM ثابت يطابق القراءة في RTL/LTR؛ لا نصوص قانونية أو روابط إلزامية مخمنة |
| Skip Link | نص مترجم وtarget ID | أول عنصر تفاعلي؛ يظهر عند التركيز؛ ينتقل إلى main وحيد يحمل tabindex=-1 |
| Page Shell | header، breadcrumb اختياري، main، footer | يملك lang وdir، عنوان الصفحة وmain وحيد؛ لا يفرض h1 داخل الأجزاء؛ الصفحة تزود h1 واضحًا |

المستهلك مسؤول عن النصوص والترجمة وصحة الروابط والصلاحيات. تمنع HTML غير الموثوقة في slots؛ تستخدم عقد DOM أو نصوصًا آمنة. IDs فريدة لكل تركيب، ولا توجد استعلامات عامة تغيّر نسخة أخرى. CSS منطقي الاتجاه، والترتيب يأتي من DOM دون قلب بصري يغيّر معنى التنقل.

شرط قبول التنفيذ: 320 و768 و1280، RTL/LTR، محتوى طويل، keyboard وعودة التركيز، غياب JavaScript، وروابط فعلية. لا تصبح هذه الأجزاء production-ready بمجرد اعتماد العقد.
