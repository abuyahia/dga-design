# IBM Plex Sans Arabic

The unmodified WOFF2 payloads for weights 400, 500, 600, 700 were extracted from the official DGA public CSS `https://design.dga.gov.sa/assets/index-PDaQ7SHU.css` on 2026-09-09. Local font-family registration matches the existing `--font-sans` token.

IBM's SIL Open Font License is retained in OFL.txt, from https://raw.githubusercontent.com/IBM/plex/master/LICENSE.txt . Fonts are included as separate original binary files, not converted or renamed internally.
