# Navigation Header

حزمة تركيب تضم Navigation Item وHeader Action وSubmenu Item. تعتمد على token.css وBase. مرجعها ملف Figma، صفحة 429:130167. حُفظت سياقات التصميم واللقطات الأصلية في _figma/ والأيقونات المصدّرة في assets/. الألوان والحالات من المرجع؛ Tokens مشتركة بدل قيم محلية مكررة.

## التحميل والاستخدام

حمّل navigation-header.css بعد Base. للاستخدام البرمجي استورد `initNavigationHeaders` من navigation-header.js، ثم `const cleanup = initNavigationHeaders(container)` واستدعِ cleanup قبل إزالة الجذر. التهيئة idempotent لكل `.nav-header` وتعيد التنظيف إلى الحالة غير المحسنة. لكل نسخة IDs فريدة. الاستعلامات والأحداث معزولة لكل جذر.

يبني scripts/build_site.py نسخة IIFE مولّدة باسم navigation-header.runtime.js للمعاينة الثابتة عبر file://، وتُحمّل defer دون متغيرات عامة. لا تعدّل النسخة المولّدة؛ مصدر ES module هو المرجع.

## العناصر والحالات

- `.nav-header__item`: رابط `<a href>` للتنقل، أو `<button type=button>` للإفصاح. لا role=menu/menubar لتصفح الموقع.
- الرابط الحالي يستخدم aria-current=page. زر القسم الحالي يستخدم data-current-section=true، مستقلًا عن aria-expanded الذي يصف فتح القائمة. المحدد أخضر مع مؤشر سفلي؛ hover/active لهما درجات مختلفة.
- الإفصاح يملك aria-controls لقائمة فريدة داخل الجذر. قبل التهيئة: المحتوى ظاهر وaria-expanded=true، والزر disabled data-enhancement-disabled. هذا التعطيل المؤقت فقط يزول عند التهيئة؛ disabled العادي يبقى.
- `.nav-header__action`: إجراء الترويسة؛ inline افتراضي، --stacked لأيقونة فوق النص، --icon-only مع aria-label، أو نص فقط. aria-pressed للتبديل أو data-selected=true يفعّل الحالة البصرية. aria-expanded يصف الفتح فقط. مالك الإجراء مسؤول عن مزامنة الحالة.
- `.nav-header__submenu-item`: رابط فرعي، يمكن أن يحتوي نصًا وصفيًا `.nav-header__submenu-description`. روابط فعلية وaria-current=page للصفحة المطابقة فقط.
- المعطل: disabled للأزرار. الرابط المعطل يحذف href ويستخدم role=link وaria-disabled=true؛ لا تعتمد على CSS لتعطيل رابط فعلي.
- focus-visible إطار داخلي 2px بلون #161616 مع فصل أبيض داخلي 2px لعناصر الترويسة؛ يبقى مرئيًا أثناء الضغط. العناصر الفرعية تستخدم إطارًا داخليًا واحدًا، أبيض على الخلفية الداكنة.

## السلوك

التفعيل بالنقر أو Enter/Space الأصليين، دون فتح بمجرد المرور. قائمة فرعية واحدة مفتوحة في النسخة. Escape يغلق الفرعية ويعيد التركيز إلى زرها؛ Escape آخر على الجوال يغلق التنقل ويعيد التركيز لزر القائمة. النقر خارج الجذر يغلق القوائم؛ خروج التركيز يغلق الفرعية. الروابط تبقى قابلة للتنقل باستخدام Tab، دون حبس التركيز.

نقاط التحول من Figma: سطح المكتب أكبر من 960px، المتوسط 600–960px، والجوال أقل من 600px. على الجوال تتحول اللوحة إلى محتوى داخل التدفق؛ على الحاسوب تمتد بعرض الجذر. دون JavaScript تبقى روابط القوائم مكشوفة. تغيير المقاس يغلق القوائم ويمنع بقاء التركيز داخل محتوى مخفي.

## الحدود

المطبق مستوى فرعي واحد، بلوحات بيضاء أو داكنة، محتواة أو كاملة العرض، ومجموعات نصية أو بأيقونات بسيطة أو محتواة. لا يوجد تنقل متداخل عميق. لا شعارات أو بحث أو مصادقة داخل الحزمة؛ يوفّرها المستهلك عبر brand/actions. اختبار القالب يغطي البحث كمستهلك لـHeader Action. الحالة production_ready=false لحين المراجعة الشاملة.

## القياسات والمعاينة

ارتفاع عناصر الترويسة 72px، الحشو 8×16px، الفاصل 4px، الأيقونة 24px والسهم 20px. المؤشر السفلي 6px بإزاحة جانبية 8px. تركيز العنصر المحدد #1b8354، وتركيز الإجراء المحدد #14573a. التعطيل بخلفية شفافة ومؤشر رمادي للمحدد فقط.

المعاينة تعرض 20 حالة Menu و60 حالة Action الأصلية، إضافة إلى 20 حالة نصية مشتقة من إخفاء الأيقونة، و16 حالة Submenu و8 حالات Toggle و4 Item Icon و12 لوحة فرعية. الاتجاهان RTL/LTR مدعومان. إعادة التوليد: python3 scripts/build_navigation_showcase.py ثم python3 scripts/build_site.py.
