# select

Native HTML control composed with Text Input markup and CSS. Load text-input.css before this CSS. The shared modifiers text-input--filled-darker, text-input--error, text-input--disabled, text-input--readonly own field states. Set native disabled/readonly attributes along with the matching modifier. aria-invalid and aria-describedby link validation errors. Select uses the original Figma chevron asset; textarea uses the native resize handle. No custom keyboard navigation replaces browser behavior.
